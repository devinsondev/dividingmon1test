# DividingMon1Test

Бездрайверная Windows-утилита: один физический второй монитор делится на 4 логических зоны 2x2.

На телевизоре 1920x1080 каждая базовая зона будет примерно 960x540.

## Как работает

Программа живёт в трее и по умолчанию выбирает первый неосновной дисплей.

Пока ты перетаскиваешь обычное окно на выбранный экран:

- бросаешь в середину одной из 4 зон -> окно занимает всю эту зону;
- подводишь к левому/правому краю зоны -> занимает левую/правую половину зоны;
- подводишь к верхнему/нижнему краю -> занимает верхнюю/нижнюю половину;
- подводишь к углу -> занимает соответствующую четверть зоны;
- перед отпусканием мыши показывается полупрозрачный preview точного места.

Главный экран ноутбука программа не трогает, пока он сам не выбран как Target display.

## Совместимость с обычным Windows Snap

Windows Snap можно оставить включённым глобально — на основном экране ноутбука он продолжит работать как раньше.

По умолчанию включён tray-пункт `Keep Windows Snap on physical edges`. В этом режиме программа:
- не перехватывает внешнюю полосу 72 px по настоящим краям телевизора;
- использует для своих внешних edge/corner-жестов виртуальную линию чуть внутрь экрана;
- если дотащить курсор прямо до физического края ТВ, наш preview исчезает и этот край остаётся Windows Snap;
- внутренние границы между четырьмя логическими submonitor работают без изменений.

Практически: для нашего snap отпускай окно, когда появился наш синий preview, не дотаскивая до настоящей рамки телевизора.

Если выключить `Keep Windows Snap on physical edges`, вернётся старое поведение — наши зоны будут использовать реальные края ТВ и могут визуально пересекаться с системным Snap.

## Snap Assist внутри логического submonitor

После snap в половину или четверть программа может показать выбор других открытых окон примерно по смыслу как Windows Snap Assist.

Правило жёсткое: предложения работают только внутри того же логического submonitor.

- left/right half -> picker появляется только в противоположной половине;
- top/bottom half -> picker появляется только в противоположной половине;
- quarter -> picker последовательно предлагает заполнить остальные три quarter того же submonitor;
- full zone -> picker не появляется;
- выбранные окна из других трёх логических submonitor автоматически не раскладываются.

В picker показываются живые DWM-превью окон. Если открыто больше четырёх подходящих окон, страницы переключаются стрелками или колесом мыши. Esc отменяет текущую серию предложений.

Функцию можно отдельно выключить через tray -> Snap Assist suggestions.

## Важно

Это НЕ четыре настоящих монитора Windows.

Поэтому:
- стандартный Maximize и настоящий fullscreen всё ещё знают про весь физический телевизор;
- отдельного taskbar для каждой зоны нет;
- драйвер, служба и права администратора не используются.

Зато обычные окна можно таскать с ноутбука на ТВ и укладывать как будто там 4 маленьких экрана.

## Безопасность

Runtime:
- без сети;
- без телеметрии;
- без записи в реестр;
- без драйверов;
- без admin;
- без keyboard/mouse injection;
- без low-level keyboard hook.

Используется WinEvent hook только для начала/конца системного move/resize. Координаты мыши опрашиваются только пока пользователь двигает окно.

Snap Assist перечисляет только обычные видимые top-level окна. Окно перемещается только после явного клика пользователя по его карточке.

Если окно elevated, Windows может не разрешить обычному процессу изменить его размер. В таком случае приложение просто ничего с ним не делает.

## Сборка

Нужен .NET 8 SDK.

    git pull --ff-only
    build-debug.bat

После успешной сборки exe будет примерно здесь:

    src\DividingMon1Test\bin\Debug\net8.0-windows10.0.19041.0\DividingMon1Test.exe

Release single-file:

    publish-release.bat

Результат:

    src\DividingMon1Test\bin\Release\net8.0-windows10.0.19041.0\win-x64\publish\

Framework-dependent release требует установленный .NET 8 Desktop Runtime.

## Использование

1. Запусти DividingMon1Test.exe.
2. Найди иконку приложения в системном трее.
3. В Target display проверь, что выбран телевизор.
4. Перетащи окно с ноутбука на телевизор.
5. Отпусти мышь, когда preview показывает нужную область.
6. Если появился Snap Assist picker, одним кликом выбери следующее окно либо нажми Esc.
7. Через Enabled можно временно отключить весь snapping.
8. Через Snap Assist suggestions можно отдельно отключить предложения окон.
9. `Keep Windows Snap on physical edges` лучше оставить включённым, если системный Snap нужен на ноутбуке.

Edge sensitivity меняет ширину зоны срабатывания у краёв логического submonitor.

## Ограничения

- активен один физический target display;
- выбор target display пока не сохраняется между перезапусками;
- некоторые приложения с нестандартными окнами могут ограничивать минимальный размер;
- elevated окна могут быть недоступны обычному non-admin процессу;
- если специально дотащить окно до настоящего физического края телевизора, там намеренно работает Windows Snap, а не наша зона;
- это user-mode эмуляция зон, а не настоящие виртуальные дисплеи.
